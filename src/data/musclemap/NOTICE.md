# Muscle diagram paths

`*-front.json` and `*-back.json` hold the body outline and per-muscle SVG paths from
[Jsplice/MuscleMap](https://github.com/Jsplice/MuscleMap) (`packages/assets/src`), converted from TypeScript
to JSON (muscle id and path data only). The authors describe the path data as original vector work, MIT licensed
(see ASSET_PROVENANCE.md in that repository). The licence text is in `LICENSE` next to this file.
